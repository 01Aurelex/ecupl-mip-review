# 华政 MIP 复习站

华东政法大学知识产权硕士（MIP）备考复习站 · 静态站点，无需构建

在线访问：<https://01aurelex.github.io/ecupl-mip-review/>

## 内容一览

| 模块 | 数量 | 说明 |
|---|---|---|
| 647 知识产权基础 | 150 分 | 四步法 + 著作权/商标/专利/竞争法四大板块拆解 |
| 821 知识产权综合 | 150 分 | 管理四线 + 政策六列表 + 八天自建方案 |

| 冲刺计划 | 30 天 | 四阶段 + 日历 + 六份交付物 |

## 本地运行

**直接打开**
```
双击 index.html
```
纯静态，无任何依赖与服务器，数据全部为本地 JS 文件，**可完全离线使用**。

**本地服务器**（推荐，字体加载更完整）
```bash
python -m http.server 8899
```
浏览器访问 `http://127.0.0.1:8899/`

> 字体通过 Google Fonts CDN 加载。离线环境会自动回退到系统衬线字体，排版不会错乱。

## 数据来源

**题库** — GitHub 公开仓库 [`lsq13060007958/patent-exam-2026`](https://github.com/lsq13060007958/patent-exam-2026)
（2026 年专利代理师资格考试题库，韩龙老师专题讲座 OCR 深度解析整理）

- 原始题量 1498（专利法 669 + 相关法 829）
- 筛选：相关法取商标法、著作权法、巴黎公约与马拉喀什条约、TRIPS 四个专题（221 题），与专利法合并
- 清洗：剔除 105 道选项被 OCR 截断或数据不完整的题目；校正 13 道题型标注与答案不符的题
- 入库：707 题，逐题保留源 ID 可溯源
- **性质说明**：这是专利代理师考试题，不是 MIP 真题（MIP 至今无公开真题）。用于建立法条手感与做题习惯，不可用于预测 MIP 题型。

**论文链接** — 全部经公开学术检索交叉核验（CNKI / 万方 / Google Scholar / 期刊官网 / 学院师资页），
每篇标注链接类型；未检出的 4 位（原晓爽、王凌红、肇旭、曹建明）如实标注并附核验线索，未作推测补全。

## 本地验证要点

1. **题库交互** — `pages/quiz.html`：切换专题与题型后题目实时刷新；点选项选中，「提交答案」后正确项显示绿色、错误选中项显示红色、解析展开；「重做」可重来。进度存于内存，刷新回到初始状态。
2. **教师筛选** — `pages/faculty.html`：搜索框支持姓名 / 研究方向 / 论文标题；分类按钮可按 647 / 821 / AI / 竞争法 / 国际 / 管理过滤；计数实时更新。
3. **论文链接** — 每篇论文下方有「查看原文 ↗」，点击在新标签打开期刊官网或机构库。目录类链接需在页面中按标题查找。
4. **跨页锚点** — 从 647 页点击教师姓名按钮，跳转到教师库并高亮对应卡片。
5. **标签页** — 647 页四个分值板块为可切换面板。
6. **打印** — 已加打印样式，Ctrl+P 导出 PDF：导航、搜索框、题库工具栏自动隐藏，标签页内容平铺展开。

## 数据边界

- 考纲、科目、分值来自华政知识产权学院招生简介与公开招生简章，**以官方最新公告为准**。
