Tool One

ECUPL-Thesis-Auto-format · 华政论文版式自动排版

依据《华东政法大学硕士学位论文格式模板》自动格式化 Word 文档。 这是本次检索到的唯一直接绑定华政的工具——它省下的是纯粹机械、却最容易反复返工的格式劳动。

覆盖的版式项

  • 页面设置：A4、页边距、1.5 倍行距
  • 标题层级识别：自动解析并套用大纲级别
  • 章强制起页：每章另起一页
  • 引言起算页码：新建 section 并把页码 start 设为 1（改 OOXML 实现）
  • TOC 样式改造：直接修改 styles.xml 中的 TOC1/2/3
  • 脚注处理、图表题注连续编号
  • 参考文献格式化、长引文处理

操作步骤

  1. 安装依赖 cd format_paper && pip install -r requirements.txt
    python-docx==0.8.11（脚本固定依赖 Python 3.7+ 环境的该版本）
  2. 运行 python format_paper.py input.docx
    指定输出：python format_paper.py input.docx -o output.docx
  3. 手动更新目录 目录是 Word 字段。打开输出文件后手动"更新目录"一次。
两个必须知道的坑 一、该仓库 README 存在未解决的 Git 合并冲突标记（<<<<<<< HEAD / ======= / >>>>>>>），clone 后需自行修复，或直接阅读 format_paper 源码取用逻辑。 二、图 / 表题注的文本格式若偏离常见的「图1 …」「表1 …」，可能无法被识别； 脚注"每页重新编号"强依赖模板设置。脚本会尽力统一版式，但务必抽查一两页。
Tool Two

lawpaper-skill · 法学论文写作全流程

融合何海波《法学论文写作》、田洪鋆《批判性思维与写作》、法大"十讲"（雷磊 / 张翔等）、 苏力 / 杨立新 / 尤陈俊 / 周大鸣等 20+ 份法学写作参考资料与《法学引注手册》第二版。 MIT 许可，双平台兼容（Hermes-agent / Claude Code）。

八阶段协作流程

阶段对应书篇协作产出
Step 0——诊断用户状态 + 确定论文类型
Step 1选题篇选题陈述草稿（研究对象 + 核心问题 + 论点 + 方法）
Step 2文献篇检索策略 + 文献验证 + 文献综述草稿
Step 3调查篇研究方法设计 + 方法部分草稿
Step 4论证篇论证结构诊断 + 论证段落草稿（Toulmin 模型）
Step 5行文篇大纲 → 引言 → 各章节 → 摘要 → 结论，逐节协作下笔
Step 6格式篇引注格式化 + 参考文献整理
Step 7伦理篇类案检索 / 法条时效 / 脱敏审查
Final——自动化质量检查（31 条规则 × 8 个维度）

五种行为循环

  • 诊断：按方法论分析已有材料，识别缺口
  • 追问：每次问一个问题，直到信息够下笔
  • 讨论：分析选项利弊，帮你判断但不替你决定
  • 下笔：按方法论写草稿，附教练批注（写法逻辑 + 风险 + 变体）
  • 回顾：不满意或后期发现前期问题，回到前面重走

八条硬性规则

  • R1 不编造文献、引文、数据、法条
  • R2 区分知道和不知道，不确定处用占位符
  • R3 不据标题推测内容，不混淆作者观点与引述观点
  • R4 生成后自查文献真实性、法条版本、判例引注完整性
  • R5 法条引用必须注明版本和时效
  • R6 判例引用必须标注案号、审理法院、裁判日期
  • R7 代笔生成的引用一律用占位符
  • R8 每次下笔必须附教练批注

自动化质检

八个检查维度：可信度 / 术语一致性 / 格式规范 / 学术语体 / 论证逻辑 / 结构完整性 / 法学引注 / 法学逻辑

为什么 MIP 特别需要它 专硕复试常要求提交实务论文或案例分析报告——这类文本的评判重点在 "分析是否到位、论证是否成链、引注是否规范"，而不是学理创新。 lawpaper-skill 的 R1—R8 硬性规则强制"不编造文献法条判例"， R5 / R6 强制标注法条版本时效与判例案号，恰好命中实务写作最容易翻车的地方。
Retest

复试准备清单

华政 MIP 复试采取差额形式，考核创新能力、学术能力和专业素养， 含外语听力和口语测试。以下是可以现在就动的准备项。

专业素养

  • 案例分析：准备 8—10 个知产实务案例（侵权判定 / 权利归属 / 损害赔偿 / 平台责任），每个写成 1500 字的定型答案
  • 实务工具熟悉度：专利检索流程、商标检索与近似判断、著作权登记与权属证明——MIP 课程里明确设了「知识产权检索」「知识产权文书」「知识产权案例分析」三门课
  • 教师研究方向：见教师论文库，114 篇附原文链接。复试被问到"你读过谁的文章"是常见开场
  • 本人研究兴趣：MIP 三个方向（知识产权保护 / 知识产权管理 / 知识产权国际治理），需提前选定并能说清理由

外语听说

  • 自我介绍：1 分钟版 + 2 分钟版，中英文各背熟
  • 专业英语：MIP 课程含「知识产权英语」——trademark / patent / copyright / trade secret / unfair competition 必须能随口说出
  • 常见问答：Why ECUPL? Why IP? What's your research plan? 准备英文答案
  • 国际视野素材：TRIPS、SEP/FRAND、跨境数据流动、AI 与著作权——可用阮开欣、董琪瑶、郑淑凤的论文作为英文讨论素材

方向选择提示

MIP 三个专业方向： 知识产权保护（依托最高人民法院"中国知识产权司法保护理论研究基地"与公检法平台支持）、 知识产权管理（聚焦上海科创中心与金融中心建设，企业 IP 管理 / 运营 / 金融三大方向）、 知识产权国际治理（全国首家承办 WIPO 中国暑期学校的高校）。 专硕培养方案要求专业实践不低于 10 学分——选方向时务必匹配你已有的实务资源： 有律所或代理机构实习经历的走保护或管理更顺，有外语优势与涉外兴趣的走国际治理。
