The Verdict

先说结论：GitHub 上没有 MIP 专项项目

用「华东政法 / 知识产权+硕士 / 知产专硕 / 647 / 821 / MIP」等 20 余组关键词， 对仓库名、描述、README 三重字段穷尽检索，并辅以全库代码搜索。结论如下。

学科太新

MIP 于 2025 年首年招生，此前华政知产只有学硕 624。专硕考纲、题型、题量全部未沉淀，没有可总结的规律。

资料在机构手里

知产专硕资料市场极小，主流资料（如震川知产专硕 821 精讲）只做 PDF 密训，不开源，GitHub 上自然找不到。

中文检索生态差

GitHub 搜索对中文多词查询解析极弱——实测「知识产权 硕士 考研」直接返回 0 条，让"确实不存在"和"没搜到"看起来一模一样。

最容易被误导的一点 市面上大量「法硕学习系统」项目（法硕非法学五科：刑法 / 民法 / 法理学 / 宪法 / 法制史）， 与华政 MIP 的 647、821 毫无交集。它唯一可借鉴的是 Obsidian Vault 的组织范式与 30 天排期方法，内容一个字都用不上。
